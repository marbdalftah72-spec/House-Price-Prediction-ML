## 📌 Project Overview

This study explores statistical and predictive modeling techniques for housing price forecasting based on demographic, geographic, and structural features.

### Key Aspects Analyzed:
- Data exploration and feature distribution analysis.
- Multi-collinearity inspection and correlation heatmaps.
- Feature engineering, outlier handling, and normalization.
- Predictive performance comparison across regression benchmarks.
